# my-cv — الموقع الشخصي / السيرة الذاتية

صفحة سيرة ذاتية عربية (RTL) بثلاثة أقسام: **ترحيب باسمك**، **نبذة من ثلاثة أسطر**، **خمس مهارات**، و**بيانات التواصل (البريد)**.

- **اللون الأساسي:** `#1f5a7a`
- **الخط:** [Cairo](https://fonts.google.com/specimen/Cairo)
- **الصور:** WebP أقل من 200 كيلوبايت داخل `assets/images/`

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
py -m http.server 8000
```
